# Настройка PiPlayer

Настройки устройства находятся в `/etc/player/player.conf`. Файл читается как shell-конфигурация: сохраняйте корректные кавычки, редактируйте его только с административным доступом и не публикуйте содержимое с паролями.

## Wi-Fi точка доступа

Подключитесь к Pi по административному SSH, например через Ethernet, и измените нужные значения в конфиге:

```sh
AP_SSID='MyPlayer'
AP_PASSWORD='replace-with-your-password'
AP_COUNTRY='RU'
AP_CHANNEL=6
AP_ADDRESS='192.168.50.1'
```

Пароль WPA2 должен содержать 8–63 печатных ASCII-символа, SSID — от 1 до 32 байт. Укажите код страны фактического использования. После сохранения примените изменения **на Pi**:

```sh
/etc/init.d/S45accesspoint restart
```

При перезапуске текущие Wi-Fi-подключения оборвутся. Подключитесь к новой сети и откройте адрес, соответствующий `AP_ADDRESS`, с портом 8080. Адрес AP используется вместе с DHCP-подсетью /24; поддерживаемая конфигурацией сборки схема — адрес, оканчивающийся на `.1`.

## Настройка при сборке

`scripts/configure.py` создаёт индивидуальные настройки и ключи в `.local/`, если их ещё нет. При последующих сборках используются существующие данные из `.local/credentials.json`: до сборки можно изменить там `ssid`, `wifi_password`, `country`, `channel`, `address`, `interface_modes` и `still_interfaces`. Затем запустите `scripts/build.sh`. Изменения этого файла сами по себе не меняют уже записанный образ или работающую Pi.

Файлы `.local/credentials.json`, `.local/admin_ed25519`, а также соответствующие файлы в `dist/` приватные. После ручного изменения конфига на Pi локальный JSON автоматически не обновляется.

## Ethernet и видео

По умолчанию `INTERFACE_MODES=0`: видео доступно по всем адресам. Для картинки на адресах выбранного интерфейса используйте `INTERFACE_MODES=1` и, например, `STILL_INTERFACES='eth0'`. Подробности и загрузка своей картинки: [ETHERNET](ETHERNET.md).

Для подготовки неподходящего видео на компьютере используйте `scripts/prepare-video.sh`, для загрузки — `scripts/upload.py`. Порядок действий и адреса: [QUICKSTART](QUICKSTART.md), формат и прямой поток: [HLS](HLS.md).
