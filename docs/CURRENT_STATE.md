## Важный вывод об эмуляторе

У QEMU raspi4b USB NIC измерено 0.864–0.889 Мбит/с, ниже битрейта demo.mp4 (~1.1 Мбит/с), из-за чего браузер буферизовался каждые5сек. Поэтому `scripts/run-qemu.sh` по умолчанию использует ARM `virt`, Cortex-A72, VirtIO-диск/сеть: **тот же Pi kernel и тот же raw**, 103–130 Мбит/с. `--raspi4` оставлен для проверки модели платы. Эмуляция не подтверждает firmware boot chain, Wi-Fi и реальный Ethernet.
