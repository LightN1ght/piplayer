## Ограничения и отдельные случаи

- Физическую microSD512MB не проверяли: проверка размера raw пройдена, аппаратный запуск был с USB32GB. Авторасширения раздела нет; после demo оставалось около248MiB под файлы, для замены нужны старый и новый одновременно.
- MP4 H.2648bit/yuv420p + AAC либо без аудио. Другие форматы готовить на компьютере через `scripts/prepare-video.sh`; Pi не транскодирует произвольные кодеки.
- Поток общий, буфер и декодирование индивидуальны у браузера. Точная синхронизация кадров не реализована и не требовалась. Пользователь заметил небольшое, точно не измеренное расхождение; максимальная нагрузка клиентами не измерялась.
- Отдельный Pixel6/Chrome подключился к AP, но HTTP не открылся. Первый клиент играл. Код ошибки/IP не получены, Pixel стал недоступен для диагностики. Причина не установлена; не объявлять случай исправленным. Успешный F2 выполнен на ноутбуке+телефоне.
- Ранний монитор с ноутбука оборвался ENETUNREACH после121с при смене маршрута ноутбука; поколение Pi не менялось. Этот прогон не был засчитан, вместо него выполнен успешный внутренний901с.
- QEMU raspi4b USB NIC измерен0.864–0.889Мбит/с, ниже demo bitrate, вызывал буферизацию. Поэтому основной launcher — ARM virt/VirtIO, тот же Pi kernel/raw,103–130Мбит/с. `--raspi4` сохранён для модели платы.
